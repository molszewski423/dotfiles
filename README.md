# dotfiles

Personal configuration files for Wayland/Hyprland desktop on Debian 13.

## Contents

| Directory | Description |
|---|---|
| `hypr/` | Hyprland compositor config |
| `waybar/` | Status bar config |
| `mako/` | Notification daemon config |
| `wofi/` | App launcher config |
| `kitty/` | Terminal emulator config |
| `fish/` | Fish shell config and functions |
| `niri/` | Niri compositor config |
| `sway/` | Sway compositor config |
| `foot/` | Foot terminal config |
| `bin/` | Helper scripts (screenshot, etc.) |

## Machine

Dell Inspiron — Debian 13, Hyprland 0.55.2

## Screenshot tooling

- `Super+S` — full screenshot to `~/Pictures/`, copied to clipboard
- `Super+Shift+S` — active window screenshot
